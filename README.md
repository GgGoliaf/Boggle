# Boggle
## (на осетинском языке)
### 1. Правила игры
* Игрок за ограниченное время ищет как можно больше слов на квадратном игровом поле с буквами, при этом слова должны состоять из трех и более букв.
* На поиск слов отводится 3 минуты.
* Буквы должны быть расположены по соседству — по горизонтали и вертикали.
* Нельзя писать слова в слове, задействуя уже использованные буквы.
* Пользователю нельзя записывать имена собственные, аббревиатуры, предлоги и союзы.
### 2. Назначение разработки
* обучающая настольная игра,адаптированная под осетинский язык. Помогает с изучением языка и пополнением словарного запаса.
### 3. Целевая аудитория
* Это классическая игра для всех, кто любит головоломки, поисковые игры и тренировку лексики. Подходит для детей от 8 лет и старше, а также для взрослых, что делает ее универсальной.
### 4. Функциональные возможности
* Динамическая генерация игрового поля 7х7 без пересечений слов.
* Полная поддержка осетинского алфавита и диграфов как одной буквы.
* Три игровые категории: «Животные», «Предметы», «Еда».
* Встроенный таймер обратного отсчета на 180 секунд.
* Счетчик оставшихся слов на поле.
* Автоматическое сохранение истории результатов в файл `scores.txt` (дата, время, категория, счет, исход).
### 5. Руководство администратора
#### 5.1. Установка и запуск
**Системные требования:**
* Операционная система Windows 10 / 11.
* Установленный пакет .NET Framework 4.7.2 или выше.

**Сборка и запуск приложения:**
1. Откройте файл проекта `Boggle.sln` через среду разработки Visual Studio 2022.
2. Убедитесь, что в верхней панели выставлен режим сборки `Debug` или `Release`.
3. Нажмите клавишу `F5` или кнопку **«Пуск»** для компиляции и запуска игры.
4. Готовый исполняемый файл игры появится по пути: `bin/Debug/Boggle.exe`.

#### 5.2. Файловая структура проекта:
* `Boggle.sln` — основной файл решения для открытия всего проекта в Visual Studio.
* `scores.txt` — текстовый файл истории игр (создается автоматически после первого матча).
* `FormField.cs` — основной файл кода для универсальной игровой формы.
* `FormField.Designer.cs` — автоматически создаваемый файл с разметкой кнопок и таблиц.
* `Cell.cs` — класс логической ячейки поля (хранит координаты X, Y и букву).
* `WordOnField.cs` — класс для разбора осетинских слов на диграфы.
* `BoardController.cs` класс генератора поля: отвечает за случайную укладку слов без пересечений.
* `GameDictionary.cs` — класс хранилища списков слов по игровым категориям.
* `FormGame.cs` — код формы главного меню игры.
* `FormCategory.cs` — код формы выбора категорий уровня.
* `FormDevelopment.cs` — код формы просмотра истории сыгранных матчей.
### 6. Руководство пользователя
**Главное меню (FormGame):**
* Отображает заголовок игры и меню выбора действий.
* Кнопка **«Играть»** — открывает окно выбора категорий.
* Кнопка **«О игре»** — открывает страницу просмотра истории результатов.

**Страница выбора категорий (FormCategory):**
* Небольшая форма поверх главного меню с заголовком «Выберите категорию».
* Кнопка **«Животные»** — запускает игровую сессию со словарем животных.
* Кнопка **«Предметы»** — запускает игровую сессию со словарем предметов.
* Кнопка **«Еда»** — запускает сессию со словарем еды.

**Игровая страница (FormField):**
* Поле **DataGridView (7х7)** — содержит перемешанные осетинские буквы и диграфы.
* Таймер **«Время:»** — запускает обратный отсчет на 3 минуты.
* Поле **«Осталось найти:»** — отображает числовой счетчик ненайденных слов.
* Поле **«Угаданные слова»** — содержит элемент `ListBox` со списком найденных слов.
* Кнопка **«Проверить»** — запускает проверку выделенной цепочки букв со словарем.
* Панель **«ПОБЕДА»** — всплывает на весь экран при успешном нахождении всех слов уровня.
* Панель **«ПОРАЖЕНИЕ»** — всплывает по центру при истечении времени на таймере.

**Страница истории игр (FormDevelopment):**
* Элемент **`ListBox`** — отображает список сыгранных матчей и результатов.
* Формат записей: Дата и время окончания | Название категории | Количество угаданных слов | Итог матча.
### 7. Руководство программиста
#### 7.1. Структура проекта
* `Boggle.sln` — Главный файл для запуска всего проекта в Visual Studio.
* `FormField.cs` — Файл кода для главного игрового поля.
* `FormGame.cs` — Файл кода для Главного меню.
* `FormCategory.cs` — Файл кода для окна выбора категорий.
* `FormDevelopment.cs` — Файл кода для окна с историей игр.
* `Cell.cs` — Класс для создания ячейки поля (хранит координаты X, Y и букву).
* `WordOnField.cs` — Класс для сборки слов и разделения осетинских диграфов.
* `BoardController.cs` — Класс генератора поля: размещает слова без пересечений.
* `GameDictionary.cs` — Класс со списками слов по всем трем темам.

#### 7.2. Основные модули
* **Создание интерфейса WinForms:** Работа окон, таймера, кнопок и таблицы с буквами.
* **Обработка игры:** Проверка соседних букв, подсчет оставшихся слов и блокировка ячеек.
* **Системные библиотеки (`System.IO`, `System.Linq`):** Используются для быстрой работы со списками букв и чтения файлов.
* **Модуль `WordOnField.cs`:** Проверяет буквы и склеивает диграфы осетинского языка в одну ячейку.

#### 7.3. Локальное хранилище (Файл `scores.txt`)
При победе или проигрыше программа дописывает новую строчку с результатом в текстовый файл `scores.txt`. Окно истории читает этот файл построчно с помощью команды `File.ReadAllLines`.
