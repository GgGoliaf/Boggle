# Игра — Boggle
## (на осетинском)
### 1. Правила игры
* В Boggle игрок за ограниченное время ищет как можно больше слов на квадратном игровом поле с кубиками букв, при этом слова должны состоять из трех и более букв.
* На поиск слов отводится 3 минуты.
* Буквы должны быть расположены по соседству — по горизонтали и вертикали.
* Можно писать слова в слове, задействуя уже использованные буквы.
* Пользователю нельзя записывать имена собственные, аббревиатуры, предлоги и союзы.
### 2. Назначение разработки
* изучение языка, пополнение словарного запаса.
### 3. Целевая аудитория
* Это классическая игра для всех, кто любит головоломки, поисковые игры и тренировку лексики. Подходит для детей от 8 лет и старше, а также для взрослых, что делает ее универсальной.
### 4. Технические требования
* Язык программирования: C#, платформа Windows Forms.
* Интерфейс: В приложении минимум 2 окна.
* Архитектура: Код проекта включает минимум 2 связанных класса.
* Хранение данных: Реализовано сохранение и чтение данных через внешние файлы.
* Git: Проект размещен в репозитории на GitHub (ссылка прилагается к проекту).
